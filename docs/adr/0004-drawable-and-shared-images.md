# Drawable and shared Images

Use `Frame::draw(&drawable)` for primitives and compositions, separating reusable `Image` handles from positioned `Sprite` values so sprites can share pictures while keeping independent placements. `Image::load(ctx, path)` synchronously decodes PNGs and queues GPU upload during loading to avoid first-draw upload preparation, replacing ADR 0003's Sprite-as-resource model and lazy upload. Image clones share GPU resources tied to the loading context without retaining decoded CPU pixels; drawing captures current values and image handles in submission order, and resources remain alive until the final owner releases them.
