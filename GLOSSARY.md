# WALZER

WALZER is a 2D game engine. Applications describe the pictures displayed in its window.

## Language

**Game**:
The application running in WALZER, including the state that determines what it draws.

**Frame**:
One complete picture drawn by the application for display in the window.

**Sprite**:
A 2D image positioned within a frame. Transparent parts of the image allow pictures beneath it to remain visible.
