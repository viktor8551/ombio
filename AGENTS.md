## Review output and README changes

These rules apply to all work in this repository, including skills and subagents.

- Present code-review findings in the conversation. Create or update a review report
  file, including under `docs/`, only when the user explicitly requests one.
- Leave all README files unchanged unless the user explicitly requests a README
  update. Implementation work alone does not authorize README changes.
